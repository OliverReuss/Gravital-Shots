# Gravital Shots

Ein 3D-Space-Shooter für PC in Unity: Das Projekt enthält ein Menü, drei Spielstages, Gegner mit unterschiedlicher Logik, Schussmechanik, Power-Ups, Score und Win/Lose-Bildschirme.

**Tech-Stack:**
- Unity 2022.3.45f1
- C# / MonoBehaviour
- URP, Shader Graph, Unity Input System
- UGUI, Audio und Partikelsysteme

**Hinweis:** Es handelt sich um ein altes, kleines Lern- und Testprojekt, das nicht weitergepflegt wird.
